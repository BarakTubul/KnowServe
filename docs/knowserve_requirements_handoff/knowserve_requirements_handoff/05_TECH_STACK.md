# Confirmed Technology Stack

| Layer | Choice | Qualification |
|---|---|---|
| Frontend language/framework | React + TypeScript + Vite | Vite dev server locally, static build on Pages |
| Styling / components | Tailwind CSS + shadcn/ui | shared design tokens/components |
| Navigation | React Router Declarative | authenticated route display is not authorization |
| Server data | TanStack Query | isolate/invalidate cache by identity/department |
| Local data | React useState/useReducer, limited Context | no Redux/Zustand in MVP |
| Forms/validation | React Hook Form + Zod | server independently validates via Pydantic |
| PDF viewer | React-PDF | custom toolbar, secure bytes from API |
| Chat streaming | SSE over Fetch POST + AbortController | stop propagates to server if possible |
| Backend + worker | Python + FastAPI services | separable runtime/container images |
| Python DB access | SQLAlchemy 2.x Async, SQL where justified | explicit permission-aware SQL |
| Migrations | Alembic | safe backward-compatible rollout |
| Database | Neon PostgreSQL + pgvector | DB is source of truth |
| Auth | focused FastAPI auth module | pwdlib Argon2id, hashed opaque DB session IDs, CSRF |
| Email | Resend | email verification |
| AI framework | LlamaIndex | library components, not central policy engine |
| Chat LLM | OpenRouter → initial OpenAI model | exact model chosen after benchmark |
| Embeddings | OpenAI text-embedding-3-small direct | independent of chat gateway |
| PDF text | PyMuPDF4LLM | future parser interface; no OCR MVP |
| Chunking | LlamaIndex SentenceSplitter | initial 512 chunk, 64 overlap; page bounded |
| Retrieval | custom SQLAlchemy + pgvector Authorized Retriever | Top-K initial 5 + adjustable threshold; no rerank MVP |
| File/object storage | Cloudflare R2, private S3 API | thin interface |
| Queue | Upstash QStash | signed Worker delivery |
| Recovery scheduler | Google Cloud Scheduler | immediate publish + periodic outbox recovery |
| Frontend hosting | Cloudflare Pages | static site |
| API and Worker hosting | Google Cloud Run | two services |
| IaC | Terraform | remote protected state, no secret values |
| Containers/local | separate API/Worker Dockerfiles + Docker Compose | frontend Vite local optional |
| CI/CD | GitHub Actions | OIDC to GCP, PR gates, deployment on approved merge |
| Secrets | Google Secret Manager Prod; `.env` local | least privilege |
| Backend tests | pytest, pytest-asyncio, HTTPX | integration on real PostgreSQL+pgvector |
| Frontend tests | Vitest + React Testing Library | component tests |
| E2E | Playwright | staged by milestone |
| Python quality | Ruff formatter/linter, Pyright | blocking practical CI gates |
| Frontend quality | ESLint, Prettier, TypeScript `strict` | blocking practical CI gates |
| Python deps | uv + `uv.lock` | frozen/locked CI install |
| TS deps | pnpm + `pnpm-lock.yaml` | frozen CI install |
| Logging | structured JSON + request/correlation IDs | Google Cloud Logging/Monitoring, basic metrics only |
| Frontend/backend interface | OpenAPI generated by FastAPI, approved contract and generated TypeScript types | Owner coordinates contract changes |
| Repo organization | Monorepo + isolated Git worktrees | core only where actually shared |

## Explicit exclusions from target
Redis/Celery/Chroma as the primary new stack; Google Drive `gdown` ingestion; JWT as primary session; WebSocket chat; Vue/NextJS; Redis-only pub/sub status truth; Sentry/full tracing; Reranker/hybrid retrieval; LangChain as main RAG engine; Google OAuth and OCR in MVP.

## Potential implementation libraries not selected
Exact OpenAI chat model, HTTP client implementation details, CSRF library/mechanism, HTTPX client generator choices, secret scanning provider, cloud metrics wiring. These are implementation details requiring minimal justified decisions, not license to reopen decided architecture.
